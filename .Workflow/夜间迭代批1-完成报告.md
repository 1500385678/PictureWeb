## 关键技术决策

1. **GitHub Contents API 而非 git push**:git push 60s 超时卡死,改走 Contents API;代价:产生 11 个独立 commit 而非 1 个 squash
2. **推 main 而非 master**:GitHub 仓库默认分支是 main(不是 master),本地 master 历史是全新独立;强推 master 会失败,所以走 main
3. **arch_type 拆表保留原值冗余**:images.arch_type 仍保留 `hotel+residential-high` 字符串作冗余,关联表是权威;迁移可逆
4. **description 降级而非 GPT 扩写**:成本/收益评估,降级 0 成本 + 立刻有信号,扩写 331×$0.01 估算 $3.3 单次但信号增量小
